## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/Juanlucasarchangelo/api-construp.git

# Acesse o diretório
cd api-construp

# Instale as dependências (exemplo Laravel)
composer install --ignore-platform-reqs
npm install

# Configure o .env
cp .env.example .env
php artisan key:generate
```
